# YTUBE — Decision log

Format: `Date | Decision | Context | Alternatives | Reason | Consequences | Revisit trigger`

---

- 2026-09-21 | **Video uploads are admin-only; `/upload` redirects non-admins to home** | The site is a curated video platform, not a UGC site | Public uploads with moderation queue; creator accounts with approval | Removes the entire abuse surface (spam, copyrighted/illegal content) and keeps the RLS model simple | No public upload path may be added without revisiting auth, storage quotas, and moderation | Revisit: if a creator program launches — then add roles, quotas, and a review queue
- 2026-09-21 | **Header, nav, footer, and homepage copy are editable from `/admin/settings` via the `site_settings` table** | Yaseen required "all the things… editable from the admin page" and control "from the header to the footer" | Hardcode copy in components; config file in the repo | Non-technical edits no longer need a code deploy; single `site_settings` table with `header`/`footer`/`home` JSON keys is simple to extend | Copy changes bypass code review; JSON schema validated in `lib/admin-actions.ts` | Revisit: if settings need versioning/preview — add a draft/publish flow
- 2026-09-21 | **Deep red + pink theme (`#c1121f` / `#ff4d6d`) with subtle neon touches** | Yaseen picked the palette; sign-in/sign-up are the visual showcase | YouTube-dark clone; generic blue SaaS theme | Distinct identity vs YouTube; neon kept to `shadow-neon*`/`text-glow*` utilities so it reads premium, not gaudy | Theme is centralized in `tailwind.config.ts`; a rebrand means retokenizing, not rewriting | Revisit: if brand guidelines arrive — extract into a formal design-token spec
- 2026-09-21 | **Mobile sidebar starts closed: initialize open for SSR, close on `<768px` in `useEffect` after mount** | Sidebar was rendering open on mobile; branching `useState` on `window` caused an SSR hydration mismatch | `useState(() => window.innerWidth >= 768)` (hydration risk); always-closed (worse desktop UX) | SSR markup stays consistent (no mismatch warning) and mobile users get the correct closed state after mount | One paint on mobile may briefly show the drawer before it closes — acceptable, no content loss | Revisit: if the flash becomes visible in practice — move to CSS-only drawer visibility
- 2026-09-21 | **Sign-in/sign-up forms stay visible in demo mode; submit is blocked with a "connect Supabase" message** | Demo mode previously replaced the auth showcase pages with the setup banner | Hide auth pages entirely in demo mode; fake client-side login | Yaseen wants the auth pages as the visual showcase; the blocked-submit message teaches the next setup step | No real auth exists until Supabase is connected — documented in `docs/SETUP.md` | Revisit: once Supabase is connected — demo branch is dead code and can be removed
- 2026-09-21 | **Server-side `requireAdmin()` (`lib/admin.ts`) + Supabase RLS as the authorization model** | Admin dashboard, uploads, and settings must be tamper-proof | Middleware-only checks; client-side role flags | `middleware.ts` can be bypassed by direct server-action calls; defense in depth (server gate + database policies) survives that | Every privileged action must remember the gate — enforced by the `security-review` skill | Revisit: if row-level needs get finer (e.g. editor role) — add role claims, not more ad-hoc checks
- 2026-09-21 | **Video ~500 MB MIME validation and thumbnail ~5 MB image validation, enforced at client + storage RLS + server action** | Large or malicious uploads could exhaust storage or serve hostile content | Client-only checks; no limits | Client gives fast feedback, RLS extension allowlists are the hard gate, `createVideoRecord()` re-validates URLs against the project's own buckets | Limits are duplicated in three layers — changes must be mirrored (see `upload-validation` skill) | Revisit: if transcoding/CDN is added — move validation into the ingest pipeline
- 2026-09-21 | **SVG removed from the thumbnail extension allowlist (stored-XSS hardening)** | `svg` in the public `thumbnails` bucket allowlist let an admin (or a compromised admin session) store script-bearing files servable from the raw storage URL | Keep svg with a sanitizer; trust admins fully | An SVG opened directly executes in the storage origin — removing it kills the vector at the RLS layer with zero UX cost (jpg/png/webp cover thumbnails) | SVG thumbnails impossible | Revisit: if vector thumbnails are ever needed — serve via a sanitizing proxy, never raw storage
- 2026-09-21 | **All privileged mutations logged to `admin_audit` and viewable at `/admin/audit`** | "High security" requirement; admin actions need a tamper-evident trail | No audit log; log to stdout only | `logAudit()` in `lib/admin-actions.ts` records admin, action, target, timestamp; RLS restricts the table to admins | Slight write overhead per mutation; log grows unbounded — add retention later | Revisit: if log volume grows — add retention/archival policy
- 2026-09-21 | **Adopted a project-local `.agents/skills/` library (11 skills) + this log + `AGENTS.md` as agent operating memory** | Agent-assisted development needs repeatable, reviewable playbooks instead of one giant prompt | Keep knowledge in chat history; copy PropEasy's bundled skills wholesale | Small, YTUBE-grounded skills route each task to the narrowest playbook; checklists cite real files | Skills must be maintained — stale skill text is worse than none; update when code changes | Revisit: after a skill proves itself in a second project — promote the generic version to a central library
- 2026-09-21 | **Strip PostgREST filter metacharacters (`,()\"` + backslash) from any user input interpolated into `.or()`/filter strings** | Security test found `app/results/page.tsx` interpolated the search query into `.or()` with only `%`/`_` stripped — commas/parens can inject extra filter conditions | Rely on `%`/`_` stripping only; avoid `.or()` entirely | Filter injection is read-only here (public `videos` rows) but reshapes results arbitrarily; the strip-list kills the vector with zero UX cost | Any new `.or()`/filter interpolation must apply the same strip — enforced by the `security-review` skill | Revisit: if search moves to Postgres full-text (`to_tsvector`) — drop the `.or()` string building entirely
- 2026-09-21 | **Baseline security headers via `next.config.mjs` `headers()` (X-Frame-Options DENY, nosniff, Referrer-Policy, Permissions-Policy, CSP with frame-ancestors 'none')** | Security test flagged missing headers; clickjacking/MIME-sniffing need a cheap baseline before any WAF | No headers; overly strict CSP that breaks Next.js inline scripts | DENY + `frame-ancestors 'none'` kill clickjacking; CSP keeps `'unsafe-inline'`/`'unsafe-eval'` for scripts because Next.js requires them — still blocks foreign origins, objects, and framing | Apply uniformly to `/:path*`; revisit when adding third-party embeds (players, analytics) — extend `img-src`/`media-src`/`connect-src` allowlists then
